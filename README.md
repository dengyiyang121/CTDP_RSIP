# 作战档案 · CTDP / RSIP

一个**本地账本**，不是教练。

它只替你做两件人记不住的事：

1. **判例**——「下必为例」。你允许过一次的事，以后必须一律允许；App 负责在你按下「允许」前，把历史判例摆到你面前。
2. **国策树**——每天最多点亮一个，崩了按堆栈回滚，但「变成习惯的天数」不丢。

计时、待办、打卡、白噪音一律没有。手机自带的东西不重做。

> 方法来自知乎《如何提高自制力？》作者 edmond（[原文](https://www.zhihu.com/question/19888447/answer/1930799480401293785)，类 MIT 授权，注明作者即可）。

## 现在能用什么

| 功能 | 说明 |
|---|---|
| 主链 | 锚点 + 单节时长；开始 / 预约 / 完成 / 中断；运行中可判定、可编辑链；#n 自动编号；分段进度格 |
| 下必为例 | **任务进行中也能直接判定**：断 → 二选一：清零，或**永久放行**；判「允许」不打断计时；确认页可返回修改；放行前自动检索相似判例；判例库可搜索 |
| 预约链 | **预约信号与神圣座位分开存**；15 分钟（可调）倒计时；设了即时启动信号就在剩 30 秒时切到第二段；超时算「该判了」 |
| 国策树 | **节点图**：正交连线 + 箭头，父在上子在下（窄屏）/ 父在左子在右（宽屏）；节点右下角「+」直接接子节点；点节点开菜单；熄灭/删除都显示级联范围；可缩放、可切列表 |
| 日结算 | **默认全亮，只勾崩了的**；国策组按配额判定；结算一天一次 |
| 水密隔舱 | 生病/出差冻结，到期一次补齐；也可提前解冻 |
| 内化进度 | 每天 +1，崩塌不归零（肉鸽式 meta） |
| 赢麻了 | 给当天命名，小赢 / 中赢 / 大赢 |
| 导出 | Markdown（可贴微信小号/打印）与 JSON（跨设备搬运） |
| 哈希链 | 每条事件含前一条哈希，可校验账本有没有被手改 |
| 提示音 | 任务/预约都排**剩 30 秒一声、正式到点一声**；方波 + 压缩器，音量更大更尖；设置里可分别试听 |
| 云同步 | 账本写进你的 GitHub **私有**仓库；打开自动拉，改动约 2 秒自动推；两边都改过**自动合并**，不再让人选“覆盖/合并”；断网自动排队重试 |

> 部署与同步的完整步骤见 [DEPLOY.md](DEPLOY.md)。

## 跑起来

零依赖、零构建。只要一个静态服务器（`file://` 下 ES module 会被拦）。

```bash
# 本机
cd projects/self-control-app
python -m http.server 8770 --bind 127.0.0.1
# 打开 http://127.0.0.1:8770
```

```bash
# 让手机连（同一 Wi-Fi）
python -m http.server 8770 --bind 0.0.0.0
# 手机浏览器打开 http://<电脑局域网 IP>:8770
```

Windows 查 IP：

```powershell
Get-NetIPAddress -AddressFamily IPv4 |
  Where-Object { $_.IPAddress -notlike '127.*' } |
  Select-Object IPAddress, InterfaceAlias
```

### 装到安卓主屏

- **HTTPS 或 localhost** 下 Chrome 才会给「安装应用」入口。局域网 http 只能当网页用。
- 想真装：丢到任意静态托管（GitHub Pages / Cloudflare Pages / Netlify），或在本机 `chrome://flags/#unsafely-treat-insecure-origin-as-secure` 里把 `http://<IP>:8770` 加进白名单。
- 装好后离线可用（Service Worker 缓存整包）。

### 数据在哪

`localStorage` 的 `ctdp.state.v1`。**只在这台设备上，不上传、无遥测。**
清浏览器数据 = 清账本。所以：每周去「档案 → 导出 JSON」存一份。

## 三个标志，别混

| 名字 | 是什么 | 例子 |
|---|---|---|
| **神圣座位** | 「开始」的动作，坐下才算 | 深呼吸三次 → 戴上降噪耳机 |
| **预约信号** | 只是预约，不是开始 | 打一个响指 |
| **即时启动信号**（可选） | 预约剩 30 秒时的第二道保险 | 连打三次响指 |

预约面板会同时显示**现在该打哪个信号**和**坐下标志**，两个不混。留空就用默认「打一个响指」。

## 国策树怎么操作

```
        ┌──────────┐
        │ 先发制人 │
        └────┬─────┘
             ↓
        ┌──────────┐
        │ 夜幕降临 │
        └────┬─────┘
             ↓
        ┌──────────┐
        │ 快速打扫 │
        └──────────┘
```

- **看结构**：连线从父节点指向子节点，箭头在子节点那一头。虚线＝在库或冻结。
- **接子节点**：点节点**右下角**的「+」。一天只能加一个，加不动会提示。
- **改节点**：点节点本体 → 抽屉里有「加子节点 / 强化 +1 / 熄灭 / 删除」，并写明会连带几个后代。
- **缩小放大**：`−` `1:1` `+`；「适配」一键缩到整棵树都在视野里；「列表」切成缩进列表（读屏/密集查看更稳）。
- **朝向**：窄屏自动改为**从上往下长**（符合手机滚动手势），宽屏改为**从左往右长**（用满横向空间）。

## 设计取舍（为什么长这样）

- **不依赖前台计时**：只记 `startedAt / endedAt`。App 被杀、锁屏、切后台都不影响正确性。所以 iOS 上也能用。
- **不催促**：没有早安推送、没有连续打卡羞辱、没有红点。唯一的通知是预约到点。
- **例外式结算**：默认全绿、只划坏的。把每日成本压到 0–1 次点击。
- **一屏一动作**：每个页面只有一个主按钮，其余收在「⋯」里。
- **可退化**：导出的 Markdown 能贴微信小号、能打印。随时离开 App 不丢系统。

## 云同步现在怎么工作

1. 打开 App / 回到前台 / 联网 → 自动拉一次。
2. 任何改动 → 2.5 秒后自动推（commit 信息带设备 ID 和时间）。
3. 两边都改过 → 不弹窗，直接按规则合并：
   - 判例、喜报、冻结、结算、事件 → 取并集，永不丢；
   - 同一条链 → 节点取并集，最近一次清零之前的节点不复活；
   - 同一个国策 → 内化天数取较大值（同一天两台设备都结算不会双倍）；
   - 删除 → 墓碑随账本同步，不会“删了又被另一台复活”；
   - 事件按时间重排后重算哈希链，合并完 `verify()` 仍然完整。
4. 推送撞上 409 → 自动重拉、合并、再推（最多 3 次）；网络失败 → 保留本地、20 秒后重试。
5. 第一次配置时如果云端只有一个空壳（比如旧版本留下的 `rev=2`），会采用内容更满的那一边，不会把两套种子国策并在一起。

正常使用不需要点“拉取 / 上传 / 合并”。设置面板里仍保留“用云端覆盖本机 / 用本机覆盖云端”作为逃生门。
